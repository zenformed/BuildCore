# Backfill BuildCore image derivatives

Derivatives are generated by **ZenformedCore** (Sharp + service role) after upload finalize.
Existing images need an explicit backfill — it does **not** run on deploy/startup.

## Prerequisites

1. Apply migration `00074_crm_documents_image_derivatives.sql`.
2. Restart/redeploy ZenformedCore with `sharp` installed.
3. From `ZenformedCore/`, ensure `.env` has `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.

## Command

```bash
cd ../ZenformedCore
npx tsx --tsconfig tsconfig.json scripts/backfill-buildcore-image-derivatives.ts
```

Useful flags:

| Flag | Default | Meaning |
|------|---------|---------|
| `--limit N` | 50 | Max candidates per run |
| `--concurrency N` | 2 | Parallel processors (max 8) |
| `--organization-id UUID` | all orgs | Scope to one org |
| `--force` | off | Regenerate even when ready |

Re-run until a run reports `candidates=0` (or only failures you accept).

## Idempotency

Rows with `derivative_status=ready`, both storage keys set, and `derivative_version=1` are skipped unless `--force`.
